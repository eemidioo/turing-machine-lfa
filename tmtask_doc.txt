3 - Convexões Léxicas

	As palavras chaves são reservadas e não podem ser usadas como nomes de estados:

		build		state		task		write		move		blank		tape
		end_build	end_task	into		run			check		initial		accept
		reject		limit		left		right		stop


4 - Padrão

<programa>   ::= { <build> | <comando> }
<build>      ::= "build" <id> <NL> { <decl> | <task> } "endbuild" <NL>

<decl>       ::= "blank" <simbolo> <NL>
               | "state" <id> [ "initial" | "accept" | "reject" ] <NL>

<task>       ::= "task" <id> "," <simbolo> <NL>
                 [ "write" <simbolo> <NL> ]
                 [ "move" <direcao> <NL> ]
                 "endtask" ( <id> | "halt" ) <NL>

<comando>    ::= "tape" <fita> "into" <id> <NL>
               | "run" <id> [ <fita> ] [ "limit" <numero> ] <NL>
               | "check" <id> <NL>

<direcao>    ::= "L" | "R" | "S" | "left" | "right" | "stop"
<fita>       ::= '"' { <simbolo> } '"'
<id>         ::= <letra> { <letra> | <digito> | "_" }
<simbolo>    ::= <letra> | <digito> | "_"
<comentario> ::= "#" { <qualquer-exceto-NL> }

3.1 - Exemplo:

	build incremento # Inicio do autômato
	
		blank '_'		
		state q0 initial
		state q1
		state qf accept
		
		task q0, 0
			move right
		end_task q0

		task q0, 1
			move right
		end_task q0

		task q0, blank
			move left
		end_task q1

		task q1, 1
			write 0
			move left
		end_task q1

		task q1, 0
			write 1
			move stop
		end_task qf

		task q1, blank
			write 1
			move stop
		end_task qf
		
	end_build
	
	tape "1011" into incremento
	run incremento limit 1000
	check incremento
